Notes on fidelity
• wbgdr2 → gdr2 is derived directly from your file's upKeyDown transitions (per frame, per player), so click/release timing round-trips exactly. Death frames are pulled from diedThisFrame when present.
• gdr2 → wbgdr2 can only reconstruct input timing (jump down/up per frame), not simulated physics — the output fills placeholder physics state so the file matches the wbgdr2 shape, but y/yVelocity/mode/etc. won't reflect real gameplay unless your web recreation re-simulates from inputs.
• Binary layout is ported directly from the reference GDReplayFormat v2 source (not just the readme, which describes a couple of fields inaccurately) — length-prefixed strings, big-endian float duration/framerate, delta+LEB128-packed inputs — and cross-checked byte-for-byte against the real C++ library in both directions. It doesn't include bot-specific extension fields.
